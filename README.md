# prediction_dfrat_athletes_ml
# Prediction du draft des athlètes - Machine Learning

## 🎯 Objectif du projet

Ce projet utilise le Machine Learning pour prédire si un athlète sera drafté à partir de différentes caractéristiques sportives et physiques.

## 📊 Données

Le projet utilise un jeu de données contenant différentes informations sur les athlètes.

## 🧹 Prétraitement

Les données ont été préparées avant la modélisation :
- traitement des valeurs manquantes
- préparation des variables
- séparation des données en ensemble d'entraînement et de test

## 🤖 Modèles de Machine Learning

Plusieurs modèles ont été testés, notamment :
- Random Forest
- Support Vector Machine (SVM)

Une optimisation des hyperparamètres a également été réalisée.

## 📈 Évaluation

Les performances des modèles ont été évaluées à l'aide de métriques de classification, notamment l'AUC-ROC.

## 🛠️ Technologies utilisées

- Python
- Pandas
- NumPy
- Scikit-learn
